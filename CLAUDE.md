# CLAUDE.md

`docs/PLAN.md` is the source of truth for scope, design, architecture and milestones; read it before starting work. Setup, run and check commands are in `README.md`.

The lobby (`lobby/`) and its deployment (`deploy/lobby/`) live in this repo; M8 deploys them on the gvm host.

Record every third-party asset in `docs/RESOURCES.md` (source, commit, license) when adding it.

Use Godot 4.7 (latest 4.7.x patch) and its newest features for performance and visuals (`docs/PLAN.md` §3.1). Check each engine feature against the 4.7 docs and migration guide instead of relying on older Godot 4 habits. A quick way to check that a class, constant or setting exists: a `extends SceneTree` script run with `godot --headless -s`.

Run `python tools/check.py` (lint, gdUnit4, headless network test) before calling work done. GDScript is statically typed; `enum` names must not shadow native classes (`Button` did).

Every commit is a semantic commit (`type(scope): summary`, Conventional Commits; see the `semantic-git` skill). PR titles too. Pushing to `main` publishes a release (see Release below).

- **Look (M9):** dark grounded sci-fi, `docs/PLAN.md` §3.2. `CharacterModel` (`client/character_model.gd`) loads any rigged model: `HUMAN` is the UAL1 mannequin, and the UAL2 clips are copied onto it at runtime (both glbs imported with humanoid bone maps, so bone names are `RightHand`, `Head`, ...; clip names lose the `_Loop` suffix on import). `skin()`/`light_up()` swap materials (skipped headless: the dummy renderer logs an error per override). `client/gear.gd` builds suit, visor, blade, shield; `EnemyView` picks robot or mannequin and its clip table (`ROBOT_CLIPS` etc.); `AttackDef.animation` names a clip of the model that uses it. Arena surfaces: `Arena._surface()` (ambientCG, world triplanar). HUD theme: Rajdhani. Check looks with `--screenshot`, e.g. `--spawn=7,0,13 --look=200,-6` (mobs) or `--encounter=boss --spawn=5,0,21 --look=200,-4 --delay=9`.
- **Lobby deploy (M8):** runs on the gvm host (`ssh grafana`) from `/root/stellamortis/deploy/lobby` (`deploy/lobby/README.md` for update and checks); coturn on the host network. Changes on that host need the user's go-ahead.
- **Players and netcode cost (M7):** max 6 players (`GameServer.MAX_PLAYERS`). netfox's server rollback is the bottleneck, not our sim: see `docs/PLAN.md` §8 before raising it. Synced state goes through `net/wire.gd` (a schema serializer for every property; add one when adding rolled back state, `tests/wire_test.gd` fails otherwise) and travels in packed groups (`SimPlayer.MOTION`/`COMBAT`/`BOLTS` as `net_*` properties, `Enemy.net_combat`/`net_bolts`); a new rolled back field must go into `STATE` and one group. Measure with `python tools/run_load_test.py` (6 bots; `--lag=MS`) and `--bench=N`; servers with `STELLAMORTIS_SERVER_STATS=1` print per-second stats.
- **Lobby (M6):** `lobby/` (Bun; `bun test` via `tools/run_lobby_tests.py`), `deploy/lobby/` (compose for gvm, `docker-compose.local.yml` for a local lobby + coturn). Game: `net/lobby_client.gd`, `net/join_log.gd`; `GameServer.lobby_url`/`room_file` (WebRTC server, room code), `GameClient.join_room`, `main.gd` `--host`/`--join=CODE`/`--lobby=URL`/`--relay-only`. `Net.room` sends the code; HUD shows it, F2 copies. The network test has a WebRTC run through a local lobby (host bot, friend bot, wrong code). Lobby protocol (`LobbyClient.PROTOCOL`) is separate from `Net.PROTOCOL_VERSION`.
- **Open items:** `docs/PLAN.md` §8 collects everything left open or decided on the way. Add to it whenever a milestone leaves something open; verification items go to M15.
- **Encounter (M5):** `sim/encounter.gd` (phases MOBS/BOSS/CLEARED, wipe reset, rolled back), `sim/mob.gd` (melee or ranged, leash), `sim/warden.gd` (sweep, slam, volley, phase 2 well via `Gravity.pull`). All enemies exist from the start on every peer (`World._add_encounter`, indices after the dummies); the encounter hides (`Enemy.Action.HIDDEN`), wakes and `reset()`s them, never spawns. `Enemy` has walking (`_walk`), attack flow (`_advance_attack`, `_on_strike`) and bolt slots (`make_bolts`, `_fire`, `_fly_bolts`; `Enemy.ACTOR_STATE`); players take enemy bolts in `SimPlayer._catch_bolts`. `AttackDef.offset` moves an attack's area forward (slam), `bolts` makes it a shot. `EnemyView` picks the skeleton per enemy kind; `BoltsView` draws any shooter's bolts. `tests/encounter_test.gd`. `--encounter=boss` skips the mobs.
- **Lock-on (M4):** `SimPlayer.target` (an `Enemy.index`, `LockOn.NONE` = -1) in `STATE`; `SimPlayer._update_lock` handles the `LOCK`/`SWITCH_LEFT`/`SWITCH_RIGHT` input bits; picking, switching and holding are pure functions in `sim/lock_on.gd`. While locked, `look_forward` is the direction to the target, not the camera yaw. Client: `GameClient._show_lock` sets `CameraRig.locked` (the rig turns itself, mouse motion becomes flick switches) and `EnemyView.set_locked` (stencil outline via `CharacterModel.outline`, dot). `tests/lock_test.gd`. MMB is lock-on now (heavy is Q only). `--bot --bot-plan=lock` locks and strafes for screenshots. netfox warns state packets exceed 508 bytes (since M3's bolts); fix in M7.
- **Ranged (M3):** `SimPlayer.weapon` (`Weapon.SWORD`/`CROSSBOW`, from `PlayerControls.weapon`), actions `DRAW`/`SHOOT`, `_shoot` and `_fly_bolts`; bolts are 4 slots of packed arrays in the player's `STATE` (`bolt_pos`, `bolt_vel`, `bolt_life`, `bolt_damage`); `Combat.aim_target`, `Combat.ray` (world layer only), `Combat.enemy_on_segment`. `CameraRig.aiming` lerps to `Combat.AIM_*`, which must stay the aim geometry. `tests/ranged_test.gd`. Layers: 1 world, 2 players, 4 enemies.
- **Combat (M2):** `SimPlayer` action state machine (`Action`, `action_time` in ticks, `Queued` input buffer, presses from `last_buttons`); attacks are `AttackDef` resources (`data/attacks/`, `Combat.attack(id)`, players index `Combat.PLAYER_ATTACKS`). `Combat.in_arc` for every hit. Enemies (`sim/enemy.gd`, `TrainingDummy`) are in group `enemies` with a stable `index` (bit in the player's `swing_hits`); players check enemy swings in `_defend` during their own tick and call `NetworkRollback.mutate(enemy)` after changing one (`SimPlayer._mutate`). Views pose `CharacterModel` (KayKit, `client/character_model.gd`) from state with `play_timed`/`loop`; it strips the weapons the KayKit glbs carry in their hand slots (all of them, all visible) and attaches ours by name (`show_prop`). `tests/combat_test.gd` covers hits, combo, stamina, roll, block, parry, riposte, death; rerun after changing numbers. Every rolled back variable must be in the node's `STATE` list, or rollback silently keeps the wrong value.
- **Gravity (M1):** `sim/layout.gd` holds the zones, asteroid and jump pads (data both sides share); `Gravity.sample`/`zone_at` (`sim/gravity.gd`, `sim/gravity_zone.gd`); `SimPlayer.step` launches from `Layout.pad_at` on jump; `SimPlayer.place(feet)` stands a body along local gravity (use it for every spawn or teleport, or the capsule starts inside the surface). `tests/asteroid_test.gd` walks around the asteroid and flies both pads with the real arena collision; rerun it after changing layout or movement numbers.
- **Boot:** `scripts/boot/main.gd` picks the role from args. No args: spawns `--server --solo` on a free port and joins it (solo exits when its player leaves). `--connect`, `--bot`, `--screenshot=PATH` (saves a PNG after 4 s and quits; use it to check visuals), `--look=YAW,PITCH` (start camera, degrees), `--spawn=X,Y,Z` (server spawn point; solo passes it on), e.g. `--spawn=40,68.1,0` is the asteroid's top, `--spawn=4,0,-7.6` stands at the swinging dummy; `--delay=S` (screenshot wait), `--graphics=low|medium|high|ultra`, `--frames=N` (a burst 50 ms apart), `--bot --bot-plan=shoot` (a windowed bot that aims along `--look` and fires full draws, for screenshots). `STELLAMORTIS_SERVER_STATS=1` makes a server print its tick loop time every second (headless with one bot: 1.6 ms average; a solo server next to an uncapped windowed client reads up to 10 ms from CPU contention). Fake latency: `tools/lag_proxy.py` (UDP proxy, `dev.py --lag=MS`, the network test uses 100 ms + 20 ms jitter).
- **Netcode:** netfox (`game/addons/netfox`, `netfox.internals`, installed by `tools/install.py` from `NETFOX_COMMIT`, gitignored; autoloads and `[netfox]` settings live in `project.godot` because the editor plugin never runs headless). Tick 30 Hz, `sync_to_physics`. Read the netfox docs (https://foxssake.github.io/netfox/, rollback caveats first) before adding rollback state. `SimPlayer.networked(peer)` adds `Controls` (input, owned by the peer), `Rollback` (`RollbackSynchronizer`, state `SimPlayer.STATE`) and on clients `Interpolator`. `sim/world.gd` (`/root/Main/Game/World`, same path on both sides) holds the arena, `Players` and the `MultiplayerSpawner`. `net/net.gd` keeps only our RPCs (`Net.PROTOCOL_VERSION`, bump on change, also when netfox state or input changes).
- **Movement:** `sim/sim_player.gd`. Players move in the plane of `up`, which follows `Gravity.sample` (`sim/gravity.gd`, constant until M1); `ref_forward` is carried along when `up` turns, and input yaw and the camera yaw (`client/camera_rig.gd`) are measured from it. `grounded` is our own floor flag, part of the rolled back state. Players do not collide with each other (layers: 1 world, 2 players). Numbers in `data/tuning.tres` (`Tuning.data()`).
- **Arena:** `sim/arena.gd`, built in code from `Layout`; collision on both sides, meshes, sun, space sky shader, environment (AgX, SSAO, SSIL, glow, distance fog, volumetric fog only from the zones' `FogVolume`s), zone particles and pads on clients only.
- **Release:** `.github/workflows/release.yml` on every push to `main` (and by hand): check, export per platform on its own runner (`tools/export.py`, presets in `game/export_presets.cfg`), artifacts kept 3 days (`ARTIFACT_DAYS`), then a GitHub Release `v<VERSION>.<patch>` with three zips. Every milestone is a minor version: the commit that finishes milestone Mn sets `VERSION` to `0.<n+1>` (release `v0.<n+1>.0`); pushes in between are patches (next free patch from the existing tags). Exported builds spawn themselves as the solo server (`OS.has_feature("template")` in `main.gd`).
- **Physics:** Jolt, 30 ticks per second, Godot physics interpolation off (netfox `TickInterpolator` instead). Renderer Forward+ (Vulkan on Linux), SMAA.
